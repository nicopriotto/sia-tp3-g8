# experiments/extras

Espacio aislado para pruebas y analisis auxiliares que no deben contaminar el flujo oficial de `experiments/ej2/`.

## Reglas sugeridas

- Reusar imports de `experiments.ej2` y `perceptron`.
- Evitar copiar el modelo o el trainer.
- Mantener aqui todo el codigo nuevo de interpretabilidad.
- Guardar resultados fuera del codigo fuente, idealmente en `results/ej2/interpretability/`.

## Uso previsto inicial

- Analisis de interpretabilidad para el MLP de clasificacion de digitos de `ej2`.
